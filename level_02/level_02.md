# LEVEL 02 : Variables

## A variable is a symbolic name that acts as a container for storing data values

### Example
```
name = "James"
age = 38
salary = 100000
active = True
```

### Python is dynamically typed 
#### This means that the type of variable is determined at runtime and can change during program execution
 
```
x = 10
x = "hello"
x = [1, 2, 3]
```

 ### Multiple assignment
```
a, b = 10, 20
```

### Same value
```
x = y = z = 0
```

### Delete
```
del x
```
